# ANÀLISI DE DADES PER A L'ENTRENAMENT I LA VALIDACIÓ DE MODELS DE DEEP LEARNING PER A LA CONDUCCIÓ AUTÒNOMA

Repositori del projecte TFG sobre: Anàlisi de dades per a l'entrenament i la validació de models de deep learning per a la conducció autònoma.

Aquest repositori està separat per tipus d'algorisme utilitzat, seguidament per les dades fetes servir per fer els experiments. 

Per muntar l'entorn de  `Python 2.7`, `keras 2.0.8` i `tensorflow-gpu 1.3` es necessiten es següents fitzers: [Entorn.zip](https://drive.google.com/file/d/1-qKl17y6af-n-Rcgqq1ubbxAJPYkBfi8/view?usp=sharing)

El codi per muntar-lo està al principi de cada `Jupyter Notebook` en el que s'ha necessitat aquest entorn.
